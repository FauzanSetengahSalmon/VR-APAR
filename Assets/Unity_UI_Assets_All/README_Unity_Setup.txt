UNITY UI ASSETS
=================

Audio:
- Loading_Beep.wav       -> Loading Beep Clip
- Phone_Ringing.wav      -> Phone Ringing Clip
- Phone_Dispatch.wav     -> Phone Dispatch Clip
- Victory_Fanfare.wav    -> Victory Fanfare Clip

Sprites:
- Icon_Avatar.png        -> Icon Avatar
- Icon_Call_Btn.png      -> Icon Call Btn
- Icon_Mute_Btn.png      -> Icon Mute Btn
- Icon_End_Btn.png       -> Icon End Btn
- Phone_Wallpaper.png    -> Phone Wallpaper

Import into Unity:
1. Extract this ZIP.
2. Put Audio and Icons into your project's Assets folder.
3. For each PNG, select it in Unity Inspector:
   Texture Type = Sprite (2D and UI)
4. Drag the corresponding files into the fields shown in your screenshot.
5. For WAV files, Unity will import them as AudioClip automatically.
